# No native binary included

This directory records only the license, README, and npm package metadata for
`lightningcss-win32-x64-msvc@1.33.0`. The prebuilt
`lightningcss.win32-x64-msvc.node` file is intentionally **not** included in the
SentinelLite 0.1.0 source-only release.

No executable form of this package is distributed by this repository. If a future
release distributes the `.node` binary, it must be treated as a new binary distribution
event and the MPL-2.0 Section 3.2 and corresponding-source questions must be revisited.
