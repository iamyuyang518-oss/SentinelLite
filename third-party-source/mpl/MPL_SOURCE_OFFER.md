# MPL-2.0 source offer template

Status: **historical template only; not executed; not applicable to the 0.1.0 source-only release.**

The SentinelLite 0.1.0 public repository distributes source only and does not
distribute an Executable Form. The exact source archives are included directly, so the
written-offer mechanism is not used for this release. Keep this file only as a template
for a future binary release.

This file is not a legal opinion and must not be published as an active offer until the
blanks are completed and reviewed. The preferred mechanism for a future binary release
would be the exact-version source archive set in `archives/`,
`lightningcss-1.33.0-npm-package.tgz`, and the exact npm-source archive
`lightningcss-1.33.0-npm-head-1d680fa-source.tar.gz`. If a distributor chooses a
written offer under MPL-2.0 Section 3.2, use wording along these lines:

---

SentinelLite 0.1.0 MPL-2.0 Source Offer

For the binary release identified as:

- Product: SentinelLite 0.1.0
- Binary/installer SHA-256: `<installer-sha256>`
- Distribution date: `<yyyy-mm-dd>`

the distributor offers the Source Code Form corresponding to the MPL-2.0 Covered Software contained in that binary. The source is available for at least three years from the distribution date, or for as long as the distributor continues to offer spare parts or customer support for that product model, whichever is longer.

How to obtain it:

- `<URL or written-request address>`
- `<contact channel>`

The offer applies only to the MPL-2.0 Covered Software in the identified binary release. It does not apply to unrelated versions or to third-party code under other licenses.

The exact source identifiers for this release are listed in `third-party-source/mpl/MANIFEST.csv` and `SHA256SUMS`.
