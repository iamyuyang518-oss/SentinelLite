# ADR 0003：签名验证范围与隐私优先

- 状态：接受
- 日期：2026-10-29

## 背景

Windows Authenticode 可帮助判断磁盘文件身份和完整性，但“签名有效”不等于“软件安全”。验证吊销或缺失中间证书可能访问网络，与本地优先、无遥测的产品原则冲突。

## 决策

- 使用 `verifysign` 封装 WinVerifyTrust，验证选中的磁盘文件；支持系统目录签名回退。
- 设置 `allow_network(false)`，结果记录 `networkUsed: false`。
- 不检查证书吊销，结果记录 `revocationChecked: false`。
- 只读取签名主体中的组织/通用名；读取失败保留“签名有效但签名者不可用”。
- 将无效、未签名、不受信任、未知区分开；不把任一种单独归为恶意。
- 明确展示验证范围：只检查磁盘文件，不检查内存映像。

## 后果

- 签名验证不会上传路径或触发在线证书查询。
- 可能把已吊销证书签名的文件仍显示为“签名有效”；UI/文档明确标注未检查吊销。
- 文件在验证后被替换或内存被篡改时，结果不能证明运行中代码可信。
- 签名主体文字可能被恶意证书伪造，仍需要用户判断。

## 重新评估条件

引入联网吊销检查、可信时间戳策略、企业证书策略或更新签名机制时，需要单独隐私和安全评审。
