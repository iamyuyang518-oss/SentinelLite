# ADR 0002：第一阶段严格只读

- 状态：接受
- 日期：2026-10-29

## 背景

安全产品如果过早提供自动处置，误报可能直接导致软件损坏、数据丢失或系统不可用。项目尚没有完整审计、恢复、持久化关联和误报回归体系。

## 决策

v0.1.0 只提供：

- 注册表与文件元数据读取；
- 进程快照；
- 处理器亲和性读取；
- 磁盘文件签名验证；
- 短时 CPU 采样。

不得提供卸载、删除、终止进程、禁用启动项、修改注册表、修改亲和性或关闭安全设置。UI 不显示无法执行的处置按钮。

## 后果

- 用户可以安全地评估当前覆盖范围和证据质量。
- 产品无法满足“清理”诉求，必须诚实标注“尚未实现”。
- 未来写操作需要新的 ADR、威胁模型、恢复设计和测试门槛。

## 约束

- 前端只调用五个固定只读命令。
- 不安装 shell/fs/http/process 插件。
- 任何新增写能力都不能藏在“扫描”或“兼容性修复”路径中。
